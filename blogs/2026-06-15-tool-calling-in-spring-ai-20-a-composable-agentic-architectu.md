An in-depth technical guide on Spring AI 2.0's rearchitected tool calling system. The post covers tool definition via @Tool annotations, the ToolCallingAdvisor recursive loop pattern, tool search for scaling to hundreds of tools, MCP (Model Context Protocol) integration, memory within tool loops, and custom advisor creation, plus migration guidance from Spring AI 1.x.
